# Burbuja

Plataforma web para la gestión y venta de **regalos personalizados**.

Burbuja nace como un proyecto aplicado a un negocio real y busca digitalizar el proceso de venta, desde la consulta de productos y su personalización hasta la gestión de pedidos y pagos.

## Tecnologías

### Backend
- Python
- Flask
- SQLAlchemy
- MySQL
- JWT
- Flask-Migrate / Alembic
- Marshmallow
- REST API

### Frontend
- React
- Vite
- JavaScript
- HTML5
- CSS3

### Herramientas
- Git
- GitHub
- Postman
- XAMPP / MySQL

## Funcionalidades actuales

- Gestión de usuarios y autenticación.
- Roles y permisos.
- Gestión de productos e imágenes.
- Opciones y características de productos.
- Personalización de productos.
- Carga de fotografías para personalizaciones.
- Gestión de órdenes.
- Control básico de stock.
- Módulo de pagos preparado para integración con Wompi.
- Frontend conectado mediante API REST.
